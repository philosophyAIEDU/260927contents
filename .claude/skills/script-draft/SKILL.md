# /script-draft — 유튜브 대본 초고

작업 폴더: 이 프로젝트 폴더(저장소를 내려받은 폴더). **입력은 주제 한 줄뿐이다** (`ARGUMENTS`). 주제가 비어 있으면 그것만 묻는다.

공통 준비·저장·검수·보고는 **`.claude/skills/_common/draft-review.md`를 먼저 읽고 그대로 따른다.**

## 절차
1. 공통 절차 1~2(준비, 근거 자료)를 수행한다. 특히 `structure.md` 2~4절(전개 순서, 훅 유형, 마무리)과 `voice.md`의 유튜브 말투를 따른다.
2. **제목 후보 3개**를 쓴다. 상위 콘텐츠처럼 시청자가 얻는 것이나 행동이 보이게 ("~하는 방법", "~구동하기"), 과장 표현은 쓰지 않는다.
3. 대본은 다음 순서로 쓴다.
   - **도입(30초 안)**: 훅 유형 A~D 중 하나로 시작한다. 하려는 일·결과·대상을 먼저 말한다. 개념 설명으로 시작하지 않는다.
   - **본문**: 결과(화면·앱·시연)를 먼저 보여 주고 그다음에 의미를 붙인다. 필요하면 번호로 나눈다 (예: "일곱 가지 팁"). 화면을 보여 줘야 할 곳은 `[화면: 무엇을 보여 준다]`로 표시한다. 근거 자료에 없는 화면은 "[사용자가 실제 화면으로 채워 주세요]"로 둔다.
   - **한계·조건**: 결론 앞에서 한계나 조건을 함께 말한다 (단정하지 않는다).
   - **마무리**: 자료 안내 → 정형구 → 좋아요·구독 요청 순서. 정형구는 `voice.md` 6절의 것을 그대로 쓴다. 자료 안내는 “고정 댓글에 링크를 넣어놓겠습니다”처럼 (실제로 링크가 없으면 "[자료 링크 준비 필요]"로 표시).
4. 말투는 구어체로 쓴다: 8~11어절로 끊고 "그래서 / 이제 / 이렇게 / 그러니까"로 잇는다. "여러분" 대신 "분들", "우리". 이모지와 과장 표현은 쓰지 않는다 (규칙 5, 6).
5. 분량 기본값은 약 1,000~1,500어절(7~10분)이다. 주제가 짧으면 짧게 쓴다 (4~5분짜리 짧은 영상도 괜찮다).
6. 공통 절차 3(저장)으로 `drafts/script/`에 저장한다. `## 초고` 맨 위에 제목 후보 3개, 아래에 대본을 넣는다. `## 적용한 규칙`에 훅 유형과 전개 순서를 적는다.
7. 공통 절차 4(검수)와 5(최종 보고)를 수행한다.
