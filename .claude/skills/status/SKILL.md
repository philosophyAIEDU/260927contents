# /status — 콘텐츠 현황 (읽기 전용)

작업 폴더: 이 프로젝트 폴더(저장소를 내려받은 폴더).

## 확인할 것
1. **raw/ 미처리 파일**: `raw/`(하위 `raw/comments/` 포함)에서 `processed/*.json`의 `source_file`에 없는 파일을 찾는다. 있으면 `/ingest`(댓글이면 `/ingest-comments`)가 필요하다고 알린다.
2. **processed/ 문서 표**: id, 포맷, 카테고리, 성과등급, 조회수, 발행일, 업로드 가능 여부(`upload_ready`), 비어 있는 태그(`missing_tags`)를 한 표로 보여준다.
3. **집계**: 포맷별 편수, 카테고리별 편수, 성과등급별 편수. 조회수는 `views_fetched_at` 날짜와 함께 보여준다 (오래됐으면 `/grade`로 갱신을 권한다).
4. **업로드 여부**: `reports/ingest-log.md`에서 업로드 완료로 기록된 id와 `processed/`의 id를 비교해 기록에 없는 것을 "업로드 기록 없음"으로 표시한다. 실제 Firestore 내용은 관리자 대시보드의 Contents Input 섹션이나 관리자 페이지(`admin/index.html`)에서 확인하라고 안내한다.
5. **Output**: `processed/_outputs/`에 결과물 초안이 있으면 개수와 제목을 보여준다.

## 보고
- 표 → 집계 → "지금 할 일" 순서로 짧게 보고한다. 지금 할 일 예: 비어 있는 발행일, 갱신이 오래된 조회수, 미처리 raw 파일.
- 수치는 `processed/`의 값을 그대로 옮기고 추정해서 채우지 않는다.
